# Screenshots

Drop README screenshots / GIFs here while testing the mod. Once they exist, they get
wired into the main `README.md` (GitHub) and `thunderstore/README.md` (package page).

## Suggested shots (use these exact filenames so they can be referenced directly)

| Filename | What to capture |
|----------|-----------------|
| `backpack-open.png` | The backpack panel fully open with a few items in the extra slots (the hero shot). |
| `backpack-peek.png` | The resting peek state at the bottom-right with the key hint visible. |
| `slot-grid.png` | The slot layout for a larger size (e.g. `AdditionalSlots = 9` or `16`) to show the 3x3 / 4x4 grid. |
| `backpack-toggle.gif` | Optional: opening/closing with `C`, showing the slide animation and the cursor jumping into / back out of the backpack. |

## Guidance
- PNG for stills, GIF (or MP4) for motion. Crop to the relevant UI; 1280px-wide or smaller is plenty.
- Lowercase, hyphenated filenames (as above). Keep file sizes modest so the README loads fast.

## How they will be referenced
- **GitHub** `README.md`: repo-relative path, e.g. `![Backpack open](Screenshots/backpack-open.png)`.
- **Thunderstore** `thunderstore/README.md`: absolute raw URL (Thunderstore is not GitHub), e.g.
  `https://raw.githubusercontent.com/DooDesch/Mimesis-InventoryExpansion/main/Screenshots/backpack-open.png`.
